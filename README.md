# CIn's Anatomy

> [!IMPORTANT]
> Esse repositório tem o objetivo de registrar nossos estudos e experências adquiridas durante
> a construção do projeto focada na SBESC 2026 - Competição de Sistemas Embarcados de 2026.

## $\textcolor{#C77DFF}{\text{➤ Objetivos}}$
O projeto CIn’s Anatomy consiste em um robô assistente voltado ao apoio à triagem pediátrica em hospitais. 
Por meio de uma interação lúdica e acolhedora, o robô conduz e automatiza a coleta dos dados de triagem da criança, 
tornando o processo menos intimidante e reduzindo os atrasos causados pelo medo e pelo choro durante o atendimento
